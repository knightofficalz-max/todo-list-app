# 📝 To-Do List App

A beautiful, fully-functional to-do list application with local storage functionality. Built with vanilla JavaScript, HTML, and CSS.

## Features ✨

- ✅ **Add, Edit, and Delete Tasks** - Manage your to-do items easily
- 💾 **Local Storage** - All tasks are automatically saved to your browser's local storage
- 🔍 **Filter Tasks** - View all tasks, only active tasks, or only completed tasks
- ✔️ **Mark Complete** - Check off tasks as you complete them
- 📊 **Task Statistics** - See total and completed task counts
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations
- 📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile devices
- ⚡ **No Dependencies** - Pure vanilla JavaScript, no frameworks required

## Getting Started 🚀

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge, etc.)

### Installation

1. Clone this repository:
```bash
git clone https://github.com/knightofficalz-max/todo-list-app.git
```

2. Navigate to the project directory:
```bash
cd todo-list-app
```

3. Open `index.html` in your web browser:
```bash
open index.html
# or for Windows
start index.html
# or for Linux
xdg-open index.html
```

## How to Use 📖

1. **Add a Task**: Type your task in the input field and click "Add Task" or press Enter
2. **Mark as Complete**: Click the checkbox next to a task to mark it as complete
3. **Delete a Task**: Click the "Delete" button next to any task
4. **Filter Tasks**: Use the filter buttons to view all, active, or completed tasks
5. **Clear Completed**: Click "Clear Completed" to remove all finished tasks at once

## Features Explained 🔍

### Local Storage
- All your tasks are automatically saved to your browser's local storage
- Your tasks will persist even after closing and reopening the browser
- Each task stores the text, completion status, and creation timestamp

### Filtering
- **All**: Shows all tasks
- **Active**: Shows only incomplete tasks
- **Completed**: Shows only completed tasks

### Task Statistics
- See the total number of tasks
- Track how many tasks you've completed
